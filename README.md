# 3D Solar System Simulation

An interactive 3D Solar System Simulation developed using Python and VPython to visualize planetary motion, moon orbits, Saturn's ring system, and real-time space animation.

The project recreates the Solar System with animated planetary revolutions, self-rotation, orbital paths, background stars, and optional texture mapping for enhanced visualization.

---

## Features

### Solar System Visualization

* Sun at the center of the system
* Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, Neptune, and Pluto
* Scaled planetary distances and sizes

### Planetary Motion

* Real-time orbital revolution
* Planet self-rotation animation
* Individual orbital speeds for each planet

### Moon System

* Earth moon simulation
* Multiple moons for outer planets
* Independent moon orbit calculations

### Saturn Ring Simulation

* Saturn ring system created using 140 ring particles
* Dynamic ring positioning around Saturn

### Space Environment

* 400 randomly generated background stars
* Dark space visualization
* Orbit path rendering for all planets

### Texture Support

* Automatic texture loading when image files are available
* Fallback color rendering if textures are missing

### Camera Animation

* Auto-rotating camera view
* Dynamic visualization of the Solar System
